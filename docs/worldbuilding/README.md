# Worldbuilding — the Waxen World (v2)

The authoring set for the shift from the 3D front-end to a text-first (Zork!-like) game. Three docs,
read in this order:

1. **[`waxen_world.md`](./waxen_world.md)** — *the canon.* The Voice Gallery (seven showpiece passages
   in the teller's voice) and the Part II generators (Seam-Stance, Faction, Society, History, People).
   This is the source; edit the other two, not this, unless the canon changes.
2. **[`style_guide.md`](./style_guide.md)** — *how to write.* The one rule (the narrator finds nothing
   strange), the voice defaults, the toolbox, the hard don'ts, the diction bank (folk idiom vs.
   authoring labels), before→after transforms, length targets, and a pin-it checklist.
3. **[`content_catalog.md`](./content_catalog.md)** — *the worklist.* Every authorable surface, its
   exact `.ron` schema, current size, a target, worked examples in voice, how the generators map onto
   the surfaces, and a plane-friendly flight plan (§10) for offline writing.

**The golden rule across all three:** the cosmology is *never named* to the player. Lethe, Penury,
Caryatid, tallow, Corollary, the forgery — these are authoring labels. The player only ever gets the
folk idiom (the fog, the cold, the come-back-wrong, a thing that real). `style_guide.md` §6 is the
translation table.

**Start here on the plane:** `content_catalog.md` §0 and §10. The biggest gap is location prose —
101 placed features with zero description text — which §E covers.
